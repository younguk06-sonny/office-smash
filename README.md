# 퇴근하고 다 부숴! (OFFICE SMASH) — 1차 버전

사무실 물건을 망치로 부수는 모바일 우선 3D 스트레스 해소 게임입니다.
Three.js(r160)를 CDN에서 불러오고, 3D 모델·이미지 파일 없이 기본 도형과 Canvas 텍스처로만 동작합니다.

## 폴더 구조

```
office-smash/
├─ index.html        화면 구조 (HUD, 미니맵, 조이스틱, 메뉴, 게임오버)
├─ css/style.css     UI 스타일 (세로 화면 우선)
└─ js/
   ├─ main.js        게임 루프, 입력, 공격 판정, 점수·콤보·해제, 폭탄·레이저
   ├─ world.js       사무실 층 배치(벽·간판·창문)와 6개 구역, 물건 배치
   ├─ objects.js     부술 수 있는 물건 18종 데이터 + 4단계 파손 로직
   ├─ player.js      1인칭 이동·충돌
   ├─ tools.js       도구 8종 능력치와 1인칭 손 모델·애니메이션
   ├─ effects.js     파편·유리·종이·폭발·레이저·분리 부품 간이 물리
   ├─ textures.js    바닥·벽·간판·모니터 화면·균열 텍스처 (Canvas 생성)
   └─ audio.js       합성 효과음, 진동
```

## 구현 내용 (1인칭 확장판)

- 1인칭 이동: 왼쪽 아래 조이스틱(멀리 끌면 달리기), 오른쪽 드래그로 둘러보기 / PC는 WASD + 마우스
- 사무실 6구역: 대표이사실 · 회의실 · 탕비실 · 경영지원부 · 리스크관리부 · 영업부 (천장 간판, 바닥 색띠, 미니맵, 현재 구역·구역별 파괴율)
- 물건 18종: 책상, 대표님 책상, 모니터, 의자, 대표님 의자, 서류 캐비닛, 복사기, 정수기, 화분, 파티션, 회의실 유리벽, 회의 테이블, TV, 화이트보드, 냉장고, 싱크대, 커피머신, 자판기, 책장, 소파
- 도구 8종: 주먹, 망치, 방망이(주변 휩쓸기), 골프채(멀리 날리기), 도끼(부품 뜯어내기), 철퇴(광역), 폭탄(던지기·폭발), 레이저(누르고 있으면 연속)
- 60초 챌린지: 점수가 오르면 도구가 하나씩 해제, 물건 하나 완전 파괴 시 +1.5초
- 무한 모드: 처음부터 모든 도구, 🔧 복구로 사무실 다시 채우기

## 배치 바꾸는 법

`js/world.js`의 `ZONES`(구역 이름·범위·색)와 `buildObjects()`(물건 위치)만 고치면 됩니다.
예: `B('copier', -12.3, 6.6, { rot: Math.PI / 2 })` → 복사기를 x=-12.3, z=6.6에 90도 돌려 배치.

## 내 PC에서 실행하기

ES 모듈을 쓰기 때문에 `index.html`을 **더블클릭해서 열면 동작하지 않습니다.** 간단한 로컬 서버로 여세요.

```bash
cd office-smash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

같은 Wi-Fi의 휴대폰에서 테스트하려면 `http://<PC의 IP>:8000`으로 접속하면 됩니다.
인터넷 연결이 필요합니다 (Three.js를 CDN에서 불러옴).

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 예: `office-smash` (Public)
2. 이 폴더의 파일을 **저장소 최상위**에 올립니다. `index.html`이 저장소 루트에 있어야 합니다.
   - 웹에서: 저장소 → **Add file → Upload files** → 폴더 안의 내용 전체를 끌어다 놓기 → Commit
   - 또는 터미널:
     ```bash
     cd office-smash
     git init
     git add .
     git commit -m "OFFICE SMASH 1차 버전"
     git branch -M main
     git remote add origin https://github.com/<아이디>/office-smash.git
     git push -u origin main
     ```
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/office-smash/` 에서 플레이할 수 있습니다.
5. 휴대폰 브라우저 메뉴의 **홈 화면에 추가**를 쓰면 앱처럼 전체화면으로 실행됩니다.
